# Tawana Technology

# created by Hashmatullah Mohammadi

**Learn · Build · Lead**

Tawana Technology is a modern and responsive educational website designed to present technology courses, practical training programs, instructors, and learning opportunities.

Our goal is to provide an attractive and user-friendly platform where students can explore courses, develop technical skills, and prepare for their future careers in technology.

## 🚀 Features

- Modern and responsive user interface
- Dark-themed design with green brand accents
- Interactive hero section
- Animated mouse network effect with particles and connecting lines
- Responsive design for mobile, tablet, and desktop
- Reusable React components
- Organized project structure
- Separate CSS files for pages and components
- Easy integration with a future backend API

## 🛠️ Technologies Used

- **React** — Building interactive user interfaces
- **JavaScript (ES6+)** — Application logic and interactivity
- **Vite** — Fast development server and build tool
- **HTML5** — Page structure
- **CSS3** — Styling and responsive layouts
- **HTML Canvas API** — Animated particle and network effects
- **React Router** — Client-side navigation

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project Directory

```bash
cd tawana
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## ✨ Mouse Network Animation

The project includes an interactive particle animation built with the HTML Canvas API and React Hooks.

Features include:

- Moving particles
- Dynamic connecting lines
- Circular interaction around the mouse pointer
- Configurable particle count and movement speed
- Responsive animation settings for different screen sizes
